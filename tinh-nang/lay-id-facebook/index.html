ID

Lấy ID Facebook (UID, Group ID, Page ID) chỉ với một cú bấm

Đang mở trang cá nhân, nhóm hay fanpage nào thì bấm một nút trong extension là có ID của trang đó để sao chép — không cần xem mã nguồn, không phải dán link sang web khác.

Cài extension miễn phí → Firefox Mở Social AIO

Chỉ cần cài extension Social AIO (miễn phí) cho Chrome, Edge, Cốc Cốc, Brave hoặc Firefox. Mọi thứ chạy ngay trên trình duyệt của bạn.

Làm được gì?

  • Lấy User ID (UID) của trang cá nhân đang mở.
  • Lấy Group ID của nhóm đang mở.
  • Lấy Page ID của fanpage đang mở.
  • ID hiện trong hộp thoại để sao chép ngay.
  • Trên fbaio.org còn có công cụ lấy UID từ link (trang cá nhân, fanpage, nhóm) trong mục Tự động hoá → APIs.
  • Miễn phí, không giới hạn.

Cách dùng

  1. Cài extension Social AIO.
  2. Mở trang cá nhân / nhóm / fanpage cần lấy ID trên Facebook.
  3. Bấm biểu tượng Social AIO → tab Công cụ → mục Facebook → Lấy User ID, Lấy Group ID hoặc Lấy Page ID.
  4. Sao chép ID trong hộp thoại hiện ra.

Câu hỏi thường gặp

UID Facebook dùng để làm gì?

UID là mã số cố định của tài khoản, không đổi khi người dùng đổi tên hay đổi link. Thường dùng để chạy quảng cáo theo tệp, lọc khách hàng, khai báo cho công cụ tự động hoá hoặc tìm lại tài khoản đã đổi tên.

Lấy được ID của người đã chặn mình không?

Không. Bạn phải mở được trang đó trên Facebook thì công cụ mới đọc được ID.

Có mất phí không?

Không. Các tiện ích trong popup extension hoàn toàn miễn phí, không giới hạn lượt dùng. Chỉ một số thao tác hàng loạt trên trang fbaio.org mới cần gói VIP.
